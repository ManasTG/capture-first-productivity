# Capture First Productivity

A simple yet useful and in some instance different To-Do application which removes the friction of writing in the task through a simple pop up like Mac's spotlight OR Linux KDE's Krunner.

## Architecture
```
User types
      │
      ▼
TextField
      │
      ▼
ListModel  ← Stores the tasks
      │
      ▼
Nothing yet
```


## Roadmap

- Make an UI system simple enough
- cpp program to take in the text and save it in the list
- Adding multiple lists
- pop up with text and save it in the list
